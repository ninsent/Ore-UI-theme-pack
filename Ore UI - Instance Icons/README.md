Ore UI - Instance Icons
---
Instance icons for Prism Launcher, drawn by LOLCATpl, the author of the Ore UI Icon Pack.

## Icons
Blast Furnace, Crafting Table, Deepslate, Diamond, Dirt, Furnace, Glass, Gold, Grass, Hay, Jukebox, Obsidian, Shroomlight, Smithing Table, Smoker, Stone, TNT.

## Installation
1. Right-click an instance in Prism Launcher and choose **Change Icon**.
2. Click **Add Icon** and select the `*_OreUI.png` files from this folder. Alternatively, click **Open Folder** and copy the files there.
3. Pick an icon from the list and click **OK**. The Ore UI icons are named `<Block>_OreUI`, for example `Stone_OreUI`.
